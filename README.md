## 4. Ideia de Projeto a Implementar

### Website para uma Barbearia

Desenvolvimento de um website para uma barbearia, com apresentação dos serviços disponíveis e respetivos preços.

O projeto pretende incluir as seguintes funcionalidades:

- Apresentação dos serviços e preços.
- Sistema de marcação de horários online.
- Registo de clientes.
- Consulta e gestão de marcações.
- Organização dos agendamentos da barbearia.

---

## 5. Conceção e Implementação do Projeto

O projeto irá integrar as tecnologias estudadas de forma autónoma com os conhecimentos adquiridos ao longo do curso.

### Tecnologias previstas

| Tecnologia | Função no projeto |
|---|---|
| HTML | Estrutura das páginas web |
| CSS | Estilização e apresentação visual |
| JavaScript | Interatividade e funcionalidades do Front-End |
| Python | Lógica de programação do Back-End |
| Flask | Desenvolvimento da aplicação web e comunicação entre componentes |
| SQL | Criação e gestão da base de dados |

### Objetivo final

Desenvolver um website funcional, intuitivo e responsivo, permitindo aos clientes consultar os serviços disponíveis, escolher horários e efetuar marcações online.

A plataforma deverá também permitir à barbearia gerir os serviços disponibilizados, os clientes registados e os respetivos agendamentos.
