4. Ideia de Projeto a Implementar

Desenvolvimento de um website para uma barbearia, com apresentação dos serviços e respetivos preços, sistema de marcação de horários online, registo de clientes e gestão de marcações.

5. Conceção e Implementação do Projeto

O projeto irá integrar as tecnologias aprendidas de forma autónoma com os conhecimentos adquiridos ao longo do curso. Serão utilizadas tecnologias como HTML, CSS e JavaScript para o frontend, Python e Flask para o backend e SQL para a gestão da base de dados.

O objetivo é desenvolver um website funcional, intuitivo e responsivo, permitindo aos clientes consultar serviços, escolher horários e efetuar marcações online, enquanto a barbearia poderá gerir os serviços e os agendamentos.
